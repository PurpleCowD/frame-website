# frame

Sitio de **frame**, un estudio de desarrollo web. Es una página estática en HTML, CSS y JavaScript que presenta el estudio, su catálogo de servicios y el formulario de contacto por pasos.

## Dónde hacer cambios

| Archivo o carpeta | Qué contiene |
| --- | --- |
| [index.html](index.html) | Los textos, la navegación y la estructura de las secciones, desde la portada hasta el footer. |
| [css/styles.css](css/styles.css) | Tipografía Avenir, colores, temas claro y oscuro, efectos de vidrio y distribución responsive. |
| [js/main.js](js/main.js) | La navegación, el selector de tema, los detalles que se abren al elegir un servicio y los pasos del formulario. |
| [assets/](assets/) | Fuentes, imágenes, logotipos de medios de pago y un modelo 3D. |
| [js/vendor/liquid-glass/](js/vendor/liquid-glass/) | El componente de vidrio utilizado por la interfaz. |
| [docs/](docs/) | El [brief inicial](docs/brief-inicial.md), el acuerdo de colaboración y las [métricas ofrecidas por plan](docs/ESTADISTICAS.md). |

Para ver los cambios en local, ejecuta `python -m http.server 8000` desde la raíz y abre [localhost:8000](http://localhost:8000).
